# Análisis exploratorio de datos

## Introducción

El objetivo es emplear todas aquellas técnicas estadísticas y de recopilación, agrupación y variabilidad que se fueron aprendiendo en el curso. 

Además de realizar todo lo anterior, se trata de descubrir, con la base de datos proporcionada, cuáles son las posibles variables causales que descifran la expectativa de vida de cada país.
